EXP-02 · open source

layerwright

An MCP server and Figma plugin that let coding agents move designs between Figma and code, on the developer's own machine.

Question
Can coding agents move a design between Figma and code without a cloud service in between?
My part
Author of 93 of its 101 commits; built in 15 days, from first commit to v1.4.1 across 14 releases.
Decision
Keep layerwright on the developer's machine: the plugin talks only to localhost, with no API keys and no cloud account.It cost · No shared cloud workspace: each developer runs it on their own machine.
Result
  • Published on npm under the MIT license, with CI.
  • My whole team now does its design-to-code work with it.
a working miniature with every case, for the curious

The record

Context

An open-source side project for Claude Code, Codex and Cursor.

Setup

  • An MCP server and a Figma plugin in TypeScript. layerwright runs locally; the plugin only talks to localhost.

Method

  • Imports HTML and Claude Design exports into Figma as editable frames with Auto Layout.
  • Builds screens from a team's own Design System and implements Figma frames with existing React components.

Side effects

Figma files are now slightly less afraid of developers.

Instruments

TypeScript · MCP · Figma plugin API · Node.js
