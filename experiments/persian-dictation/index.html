EXP-05 · open source

Dictation with what the browser already has

Persian and English dictation inside the editor, using only the browser's own speech API.

Question
Can people dictate Persian and English feedback inside the editor using only what the browser already has?
My part
Built and shipped it on 5 screens; published the plugin on npm.
Decision
Use the browser's Web Speech API through the editor's own commands, with zero new dependencies.It cost · It depends on each browser's speech service, which can stop or fail on its own: hence the watchdog and the retries.
Result
  • Shipped to production on 5 evaluation, 360-feedback, nomination and check-in screens.
  • Published a standalone CKEditor 5 plugin on npm.

The record

Context

Writing long feedback is slow. A separate speech service or an audio relay would add a new system to run.

Setup

  • The browser's Web Speech API inside CKEditor, inserted through the editor's own commands so it joins undo.

Method

  • A Persian transcript normaliser and a resilient session model (restart on end, retries with backoff, an idle watchdog).
  • Zero new dependencies.

Instruments

TypeScript · CKEditor 5 · Web Speech API
